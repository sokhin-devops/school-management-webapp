# School Management SaaS — Product Overview

## Purpose

A flexible multi-school School Management SaaS supporting Primary Schools, Secondary/High Schools, Colleges, Universities, Language Centers, Training Centers, Vocational Schools, and other institutions.

## Core Principle

One platform with:
- Common Core
- School Type Configuration
- Configurable Academic Structure
- Optional Modules
- Configurable Terminology

Do not create separate applications for different school types.

## Common Core

- Dashboard
- People
- Users & Roles
- Settings
- Finance
- Reports
- Notifications
- Attendance
- Authentication

Academic structure is the most configurable area.

## Development Rule

Read this file and the relevant module/architecture files before implementing a feature. Preserve confirmed UX decisions, reuse existing components, keep responsive behavior, and avoid unnecessary complexity.
