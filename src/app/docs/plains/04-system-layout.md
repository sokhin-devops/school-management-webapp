# System Web App Layout

Authenticated application layout:
- Left Sidebar
- Topbar
- Content

Do not replace the left sidebar with top navigation.

## Responsive

Desktop: Sidebar + Topbar + Content
Tablet: Collapsible Sidebar + Topbar + Content
Mobile: Drawer Sidebar + Topbar + Content

## Topbar

- Notifications
- Help
- Selected Branch
- User menu

The selected Branch is global. Changing it changes branch-scoped data.
