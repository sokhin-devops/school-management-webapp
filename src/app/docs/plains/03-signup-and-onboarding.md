# Sign Up & School Onboarding

## Flow

Landing Website
-> Sign Up
-> Choose Plan
-> School Setup
-> Add School
-> Add Branch
-> Academic Structure
-> Done
-> Dashboard

## Sign Up

- Name
- Email
- Password
- Confirm Password

## Choose Plan

- Starter
- Professional
- Enterprise

## School Setup

Progress:
`01 School -> 02 Branch -> 03 Academic`

Do not add a Review step.

Final action:
`Done`

After Done:
`Dashboard`

Do not create a separate School Admin step. The account owner becomes the initial owner/admin automatically.
