# Users & Roles

Submenus:
- Users
- Roles

## Users

Primary action:
`Invite User`

Do not call it Add User.

Branch selection supports multiple branches.

## Default Roles

- Admin / Owner
- Accounting
- Teacher
- Parent
- Student

Do not include Branch Admin as a default role.

Default roles cannot be edited or deleted.

Accounting, Teacher, Parent, and Student can be opened in View mode.

## Custom Roles

Users can:
- Create custom roles
- Select permissions
- Assign branches

Permission UI uses a checkbox tree.

Example:
Students
- View
- Create
- Edit
- Delete

Finance
- View
- Create
- Edit
- Delete
